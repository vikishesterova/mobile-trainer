# Сервер приема отзывов

Подготовленный модуль для Site `appgprj_6ad78ba940008191b0c2c8a9b9e1e037`.
При публикации синхронизировать `feedback-relay.mjs` с `lib/feedback-relay.mjs` в исходниках Site и выполнить штатную сборку/публикацию Sites.

Первая попытка с `retry:false` отправляет один POST в Apps Script. Ответ `ok` подтверждает завершившийся `appendRow`. Повторная попытка сначала ищет строку с прежними датой, оценкой и комментарием. Старые клиенты без поля `retry` сохраняют эту проверку. При потере ответа POST сервер проверяет строку чтением, не повторяя запись автоматически.

Порядок выпуска: опубликовать модуль сервера, затем выпустить изменения `js/app.js` и версии скрипта в `index.html`. Старая версия сервера игнорирует дополнительное поле, но не ускоряет обработку.

Проверки: `node --test feedback/relay/*.test.mjs`.
