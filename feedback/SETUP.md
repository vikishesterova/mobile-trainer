# Подключение сбора отзывов: пошаговая памятка

Собираем оценки и комментарии с финального экрана тренажера в Google Таблицу,
а смотрим их на странице-дашборде.

---

## Часть 1. Создаем Google Таблицу

1. Открой [sheets.new](https://sheets.new) (создастся пустая таблица).
2. Переименуй лист, как удобно, например «Отзывы».
3. В первую строку впиши заголовки (по ячейкам):
   - `A1`: Дата
   - `B1`: Оценка
   - `C1`: Комментарий
4. Таблицу пока не закрывай — понадобится для шага 3.

---

## Часть 2. Добавляем код Apps Script

1. В таблице сверху: **Расширения → Apps Script**.
2. Откроется редактор. Удали весь шаблонный код.
3. Открой в проекте файл `feedback/appsscript.gs`, скопируй его содержимое
   целиком и вставь в редактор.
4. Нажми **💾 Сохранить** (или Cmd+S). Имя проекта можно оставить как есть.

---

## Часть 3. Разворачиваем веб-приложение

1. Справа сверху нажми **«Развернуть»** (Deploy) → **«Новое развертывание»**.
2. Нажми шестерёнку (иконка настроек типа развертывания) и выбери
   **«Веб-приложение»** (Web app).
3. В поле **«Кто имеет доступ»** выбери:
   - «Все, у кого есть ссылка» (или «Любой» / Anyone).
4. Нажми **«Развернуть»**.
5. Возможно, Google попросит **предоставить доступ** / подтвердить аккаунт —
   нажми «Предоставить доступ» → выбери свой аккаунт → «Разрешить».
6. Скопируй **URL веб-приложения** — он выглядит так:
   `https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXX/exec`

⚠️ Это главный шаг. Без него сбор не заработает.

---

## Часть 4. Вставляем URL в тренажер и дашборд

Открой в проекте два файла и подставь скопированный URL:

**1) `js/data.js`**
```js
const SURVEY_ENDPOINT = "";
```
→ замени на
```js
const SURVEY_ENDPOINT = "https://script.google.com/macros/s/XXXXXXXX/exec";
```

**2) `dashboard.html`**
```js
var DATA_ENDPOINT = "";
```
→ замени на
```js
var DATA_ENDPOINT = "https://script.google.com/macros/s/XXXXXXXX/exec";
```

(В обоих местах один и тот же URL.)

## Как проверить

1. Открой тренажер, пройди до конца, поставь оценку и напиши комментарий,
   нажми **«Отправить оценку»**.
2. Открой Google Таблицу — там должна появиться новая строка
   (Дата / Оценка / Комментарий).
3. Открой дашборд:
   `https://viktoriashesterova28-star.github.io/mobile-trainer/dashboard.html`
   — там увидишь число ответов, среднюю оценку и список отзывов.
   Нажми **«Обновить»**, чтобы подтянуть свежие данные.

---

## Если что-то не работает

| Проблема | Решение |
| --- | --- |
| В дашборде ошибка «Не удалось загрузить данные» | Проверь, что URL вставлен и в `DATA_ENDPOINT`, и что веб-приложение развернуто с доступом «у всех» |
| Ответы не появляются в таблице | Проверь URL в `SURVEY_ENDPOINT` и что код скрипта сохранен и развернут заново |
| Сменила/пересоздала скрипт | URL меняется — обнови его в обоих файлах и запушь заново |
| Хочешь чистый лист | Можно очистить строки под заголовком — дашборд покажет «Ответов пока нет» |

---

## Безопасность

- Скрипт принимает только оценку и текст комментария, без личных данных
  (имя, почта, устройство).
- Дашборд открыт по ссылке — не публикуй его в открытых чатах, если
  комментарии считаешь чувствительными.
